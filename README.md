🌙 MoodBuddy — Mental Health Chatbot

A rule-based mental health companion chatbot that detects emotions from user input using keyword pattern matching and responds with personalized encouragement, actionable tips, inspirational quotes, and a guided breathing exercise.

MoodBuddy is a beginner-to-intermediate level web project that simulates a mental health chatbot using rule-based natural language processing. Instead of an AI model, it uses a hand-crafted keyword detection engine — looping through predefined rules to match the user's emotional state and return a structured, supportive response.
It is designed to feel warm, calm, and human — with a dark night-sky theme, smooth animations, a typing indicator, quick-select mood chips, and a full-screen guided breathing exercise for moments of stress or anxiety.
